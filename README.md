# Klanvision Java Programming Internship

This repository contains the Java projects developed as part of my
Klanvision Java Programming Internship.

## Projects

### Task 1 - Library Catalog System

A console-based Java application for managing a library catalog.

**Features:**
- Add books
- Search books
- List books
- View book details
- Remove books
- Duplicate book ID validation
- Input validation

**Technologies:**
- Java
- OOP
- Collections
- Exception Handling

---

### Task 2 - Klanvision Bank - Banking System

A console-based banking application developed using Java.

**Features:**
- Create bank accounts
- View account details
- Search accounts
- Deposit money
- Withdraw money
- Transfer money
- View transaction history
- Display all accounts
- File-based data persistence
- Input validation

**Technologies:**
- Java
- OOP
- Collections
- File Handling
- Exception Handling
